# qbox

Нативный клиент VPN/прокси для Windows на Go: интерфейс на
[MyGo](https://github.com/egoist/mygo) (`ui`, без web-view), ядро
[sing-box](https://github.com/SagerNet/sing-box) подключено как Go-библиотека,
а не как отдельный процесс.

## Статус

MVP для Windows 10/11 x64:

- TUN-режим с автоматической маршрутизацией и перехватом DNS;
- режим системного прокси Windows без прав администратора;
- подписки в формате base64/URI-списка и sing-box JSON;
- VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, SOCKS, HTTP;
- режимы Global / Rules / Direct;
- несколько переключаемых профилей маршрутизации;
- обход локальной сети, обход РФ по rule-sets, блокировка рекламы;
- свои списки доменов и CIDR для proxy/direct;
- живой график трафика за последние 60 секунд и счётчики принято/отдано;
- вкладка активных соединений;
- пинг нод через реальный протокол ноды, таймаут 6 с и 6 параллельных проверок;
- тема, акцентный цвет и скругления интерфейса;
- конфигурация в `%AppData%\qbox\config.json`.

Clash YAML и мобильные платформы в этот MVP не входят.

## Требования

- Windows 10/11 x64 (arm64 собирается, но не проверялся);
- Go 1.27.4+;
- права администратора для TUN: создание Wintun-адаптера и изменение
  таблицы маршрутов требуют elevation.

Для системного прокси права администратора не нужны.

## Сборка

```powershell
.\scripts\build.ps1
```

Скрипт выставляет обязательные build tags sing-box и вызывает MyGo:

```powershell
$env:GOFLAGS = "-tags=with_gvisor,with_quic,with_utls,with_grpc"
go tool mygo build -platform windows/amd64 -skip-installer
```

Без `with_gvisor` не будет mixed-стека TUN, без `with_quic` — Hysteria2/TUIC,
без `with_utls` — uTLS/REALITY.

Результат: `build/windows-amd64/qbox.exe`. Отдельный `wintun.dll` не нужен:
sing-tun встраивает официальный Wintun и загружает его из памяти.

## Wintun

Пакет `sing-tun` (зависимость sing-box) содержит официальный подписанный
Wintun 0.14.1 и загружает его через `memmod`, без поиска DLL в каталоге
приложения. Это исключает подмену `wintun.dll` рядом с qbox.exe. Копия
лицензии Wintun — `third_party/wintun/LICENSE.txt`.

## Запуск

1. Запустите `qbox.exe`.
2. Слева нажмите «Добавить подписку» и вставьте URL.
3. Выберите ноду или «Авто» в списке справа.
4. Нажмите «Подключиться». В режиме TUN Windows запросит UAC: приложение
   перезапустится с правами администратора и автоматически подключится.

Закрытие окна сворачивает qbox в трей: подключение продолжает работать.
Значок qbox в трее открывает окно, позволяет подключиться/отключиться и выйти.
При выходе ядро синхронно останавливается: TUN-адаптер, маршруты и системный
прокси возвращаются в исходное состояние до завершения процесса.

Приложение работает как один экземпляр; повторный запуск передаёт управление
первому.

## Интерфейс

Верхняя строка окна содержит меню «Файл», «Маршрутизация», «Настройки» и
кнопки свернуть/развернуть/закрыть.

- **Файл** открывает read-only окна с `config.json`, последней конфигурацией
  sing-box и журналом `qbox.log`.
- **Маршрутизация** показывает список профилей с отметкой активного. Там же
  можно создать, переименовать или удалить профиль и открыть окно
  «Просмотр всех маршрутов» с редактированием правил.
- **Настройки** — отдельная страница: внешний вид, TUN/системный прокси, DNS,
  журнал и файлы.

Слева — подписки. У каждой есть цветная иконка с первой буквой названия и меню
«Обновить / Переименовать / Удалить». Справа — вкладки «Ноды», «Логи» и
«Подключения», кнопки «Пинг», «Перезапустить» и «Подключиться/Отключиться», а
внизу — карточка трафика с графиком скорости за 60 секунд.

Ошибки показываются строкой под шапкой, короткие сообщения — там же и
исчезают по кнопке закрытия.

## Режим TUN и системный прокси

По умолчанию включён TUN: весь трафик перехватывается адаптером Wintun, DNS
перенаправляется в sing-box, нужны права администратора.

Если выключить «Режим TUN» на странице настроек, qbox поднимает локальный
`mixed`-inbound (HTTP + SOCKS) на `127.0.0.1` и включает системный прокси
Windows (WinINET) для текущего пользователя. Администратор не нужен.

- Порт задаётся в настройках; `0` означает свободный порт при каждом запуске.
- Перед включением qbox сохраняет прежние настройки прокси, а при остановке,
  рестарте и выходе возвращает их. Если процесс был завершён аварийно, настройки
  восстанавливаются при следующем запуске, но только если прокси всё ещё
  указывает на qbox.
- Системный прокси видят не все приложения: QUIC, игры и программы со своим DNS
  могут обойти его. Корпоративные домены, которые приложение резолвит само,
  могут не работать. Для полного перехвата нужен TUN.
- Для приложений, которые используют системный прокси, правила доменов,
  adblock и обход LAN/РФ работают так же, как в TUN.

Переключение между TUN и системным прокси применяется после перезапуска
подключения. При переходе на TUN qbox запрашивает UAC.

## Пинг нод

Вкладка «Ноды» → «Пинг»: для каждой ноды поднимается временный sing-box
без TUN и выполняется реальное TCP-соединение через протокол ноды к
`1.1.1.1:443`. Задержки появляются по мере проверки; пока идёт тест, кнопка
показывает прогресс и позволяет отменить его. Для каждой ноды есть таймаут
6 с и общий watchdog 12 с. Причина ошибки пишется в журнал. Пинг работает и
без активного подключения.

## Маршрутизация

Профили открываются в меню «Маршрутизация». Каждый профиль хранит режим,
обход LAN/РФ, блокировку рекламы и свои списки доменов/CIDR. Новый профиль
создаётся копией текущего; профиль можно переименовать или удалить.
Переключение на профиль с другими правилами применяется к работающему
подключению сразу и перезапускает ядро.

- **Global** — финальный маршрут через ноду; LAN и блокировка рекламы
  действуют по настройкам, списки и обход РФ игнорируются.
- **Rules** — правила и списки, финальный маршрут через ноду.
- **Direct** — без прокси; TUN/mixed, DNS hijack, LAN и adblock продолжают
  работать.

Порядок правил: sniff → трафик самого qbox напрямую → блокировка рекламы →
LAN напрямую → свои proxy-списки → свои direct-списки → обход РФ → финальный
маршрут. Смена ноды перезапускает ядро; изменения маршрутизации применяются
кнопкой «Перезапустить».

Direct-домены и домены обхода РФ резолвит системный DNS, а не remote DNS
через прокси. Это нужно для корпоративных имён: например, если добавить
`geocad.ru` в «Direct: домены», `jira.geocad.ru` и `gitlab.geocad.ru`
получат внутренние адреса от DNS вашей сети. Remote DNS при этом продолжает
использоваться для остального трафика.

Rule-sets скачиваются с `SagerNet/sing-geosite` и `SagerNet/sing-geoip` в
`%LocalAppData%\qbox\rulesets` и кешируются с ETag.

## Файлы

| Что | Где |
|---|---|
| Конфигурация | `%AppData%\qbox\config.json` |
| Резервная копия | `%AppData%\qbox\config.json.bak` |
| Настройки системного прокси | `%AppData%\qbox\system-proxy.json` |
| Кэш sing-box | `%LocalAppData%\qbox\cache\cache.db` |
| Rule-sets | `%LocalAppData%\qbox\rulesets` |
| Журнал | `%AppData%\qbox\logs\qbox.log` |

`config.json` содержит URL подписок и токены. Окно просмотра доступно только
для чтения, но учитывайте это при передаче скриншотов.

## Тесты

```powershell
.\scripts\test.ps1
```

Скрипт прогоняет unit-тесты, `go vet`, `mygo vet`, а тест UI собирает в
`build/test` и запускает оттуда (в некоторых конфигурациях Windows Defender
блокирует тестовый exe в `%TEMP%`).

Статический анализ и проверка уязвимостей:

```powershell
.\scripts\check.ps1
```

CI (`.github/workflows/ci.yml`) выполняет те же шаги на Windows.

Проверка TUN выполняется вручную на машине с правами администратора и
реальной подпиской: IP/DNS-leak, LAN, обход РФ, adblock, смена ноды.
Проверка системного прокси — вручную: включение, работа браузера, возврат
прежних настроек, восстановление после завершения процесса.

## Ограничения

- sing-box линкуется как библиотека, поэтому qbox распространяется под GPLv3.
- Изменение ноды или маршрутизации перезапускает ядро и рвёт соединения.
- Системный прокси — не замена TUN: охват зависит от приложения и его DNS.
- Нет автоматического запуска при входе: elevated-автозапуск требует
  Task Scheduler и отдельного этапа.
- Принудительное завершение процесса в режиме TUN может оставить маршруты, а в
  режиме системного прокси — настройки прокси до следующего запуска qbox.
  Используйте «Выход» в меню трея или обычное завершение Windows.
- Неподписанный exe может вызывать предупреждение SmartScreen.

## Если Windows не даёт назначить IPv6

Ошибка `configure tun interface: set ipv6 address: Element not found`
означает, что IPv6 отключён в системе или на адаптере. qbox автоматически
повторяет запуск с IPv4-only TUN и показывает предупреждение. Чтобы не
повторять попытку каждый раз, включите в настройках «Отключить IPv6 в TUN».
