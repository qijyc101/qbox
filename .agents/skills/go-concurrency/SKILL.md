# Конкурентность в Go
- Назови владельца каждой goroutine и путь выхода; не запускай без условия остановки.
- Передавай context первым параметром, освобождай ресурсы через defer cancel().
- Для общего состояния используй mutex; не держи блокировку во время долгого I/O.
- Закрывай канал со стороны владельца отправки после завершения всех отправителей.
- Ограничивай очередь и число исполнителей. Определи поведение при переполнении.
## Пример отправки с отменой
```go
select {
case <-ctx.Done():
    return ctx.Err()
case jobs <- item:
    return nil
}
```
## Приемка
Проверь отмену, пустой вход, ошибку исполнителя, завершение очереди, гонки и повторные вызовы. Не используй time.Sleep как синхронизацию теста. Запусти go test -race для измененного пакета.
