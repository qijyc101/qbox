# HTTP API
- Согласуй публичные маршруты, методы, коды ответа и схему JSON.
- Ограничь размер входного тела. Проверяй декодирование и семантику данных.
- Передавай r.Context() в бизнес-логику и запросы к хранилищу.
- Настрой ReadHeaderTimeout, IdleTimeout и подходящий бюджет обработки.
- Завершай сервер через Shutdown с отдельным ограниченным context.
- Не раскрывай внутренние сообщения ошибок и секреты в ответах.
## Приемка
httptest: успех, неверный JSON, отсутствие ресурса, ошибка зависимости, отмена. Проверь контракт Content-Type и статус до записи тела.
Предпочитай net/http; добавляй фреймворк только под конкретную потребность.
